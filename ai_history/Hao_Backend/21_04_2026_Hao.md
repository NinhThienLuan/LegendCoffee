## 2. Chi tiết các API (Request - Response - Chức năng)

### A. Nhóm API AJAX (Dùng cho Checkout)
Hệ thống gọi API này khi người dùng thao tác trên màn hình Checkout.

1. **Lấy Tỉnh/Thành phố:**
   - **Endpoint:** `GET /api/shipping/provinces`
   - **Request:** Không có.
   - **Response:** `List<ProvinceDTO>` - Chứa `ProvinceID`, `ProvinceName`.
   
2. **Lấy Quận/Huyện:**
   - **Endpoint:** `GET /api/shipping/districts`
   - **Request:** `provinceId` (Query param).
   - **Response:** `List<DistrictDTO>` - Chứa `DistrictID`, `DistrictName`.

3. **Lấy Phường/Xã:**
   - **Endpoint:** `GET /api/shipping/wards`
   - **Request:** `districtId` (Query param).
   - **Response:** `List<WardDTO>` - Chứa `WardCode`, `WardName`.

4. **Tính phí và Ngày giao dự kiến:**
   - **Endpoint:** `POST /api/shipping/options`
   - **Request (JSON):** `AddressQueryDTO` { `districtId`, `wardCode`, `weight`, `insuranceValue` }.
   - **Response (JSON):** `List<ShippingOptionDTO>` { `serviceId`, `serviceName`, `shippingFee`, `leadtime` }.

---

### B. Nhóm API Quản lý đơn hàng (Order Management)

1. **Tạo đơn hàng & Giao vận:**
   - **Endpoint:** `POST /checkout/place-order`
   - **Request Form:** `CheckoutRequestDTO` (Họ tên, SĐT, Địa chỉ, Mã tỉnh/huyện/xã, Mã dịch vụ GHN).
   - **Workflow:** 
      - Backend lưu đơn vào SQL Server.
      - Gọi API GHN `/create`: Truyền thông tin người nhận + Items + Mã Shop.
      - Nhận về `order_code` (Mã vận đơn) và lưu vào `ShippingInfo`.
   - **Response:** `Redirect` tới trang Tracking.

2. **Huỷ đơn hàng:**
   - **Endpoint:** `POST /orders/{orderId}/cancel`
   - **Request:** `orderId` (Path variable).
   - **Xử lý:** Kiểm tra `ShippingInfo.status == "ready_to_pick"` trong DB. Nếu đúng, gọi API GHN `/cancel`.
   - **Response:** `Redirect` về `/track` kèm thông báo thành công/thất bại.

---

### C. Nhóm API Thông tin & Webhook (Real-time Status)

1. **Nhận Webhook từ GHN:**
   - **Endpoint:** `POST /webhook/ghn`
   - **Request Body (JSON):** `WebhookPayloadDTO` { `OrderCode`, `Status`, `Warehouse`, `Time` }.
   - **Chức năng:** Cập nhật ngay lập tức cột `status` trong bảng `ShippingInfo` và log lịch trình mới.
   - **Response:** `{"status": "received"}`.

2. **Truy vấn trạng thái (Tracking):**
   - **Endpoint:** `GET /api/shipping/track/{orderId}`
   - **Request:** `orderId`.
   - **Response (JSON):** `OrderStatusDTO` { `ghnOrderCode`, `status`, `statusLabel`, `logs` (Danh sách lịch trình thời gian) }.

## 4. Tham khảo Mapping thông tin (Glossary)

- **ready_to_pick**: Đơn mới tạo, đang chờ shipper đến lấy. (Được huỷ).
- **picking**: Shipper đang đi lấy hàng. (Hạn chế huỷ).
- **transporting / delivering**: Hàng đang di chuyển hoặc đang đi giao. (Không được huỷ).
- **delivered**: Đã giao thành công.
- **cancel**: Đơn đã bị huỷ.
